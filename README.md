# Surfd Web (Classic Counter-Strike Surf in Browser)

Reproduction et miroir web complet de **Surfd** (`https://surfd.net/`), le jeu de surf style Counter-Strike / Source tournant directement dans le navigateur en WebGL (Three.js).

---

## 🎮 Jouer en ligne

- **URL GitHub Pages** : `https://mohamedguell.github.io/surfd/`

---

## 🚀 Fonctionnalités & Cartes incluses

- **Cartes pré-téléchargées et embarquées localement** :
  - `surf_boreas` (Carte par défaut)
  - `surf_mesa`
  - `surf_beginner`
  - `surf_utopia`
  - `surf_kitsune`
  - `surf_lux`
  - `surf_rookie`
- **Fallback automatique** : Toutes les autres cartes du jeu officiel sont chargées à la demande via les serveurs avec support CORS.
- **Sauvegarde locale** des temps, records et paramètres de sensibilité/clavier.
- **Accès complet sans blocage** : Grâce à l'hébergement direct sur GitHub Pages, le site est accessible sur les réseaux d'entreprise ou d'école où les domaines de jeux sont restreints.

---

## 🕹️ Commandes

- **Z / Q / S / D** ou **W / A / S / D** : Déplacement
- **Espace** : Saut / Auto Bhop
- **Souris** : Regarder / Orienter la trajectoire de surf
- **R** : Recommencer la course
- **Échap** : Menu des paramètres et choix de la carte
